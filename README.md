## Azure-Compliance-Processing-Pipeline (Prototype)

This is a prototype FastAPI + PostgreSQL pipeline for ingesting compliance policy documents, chunking them into clauses, classifying each chunk, computing similarity to a control library, and exporting structured results. It is designed to run **locally** via Docker Compose while mirroring a cloud-ready, Azure-aligned architecture.

> Full details on architecture, Azure alignment, API usage, evaluation, and next steps will be filled in after implementation is complete.
